WordPress yönetim panelinden WhatsApp Business gelen kutusu. Message Manager platformuna bağlanır.

== Description ==

Bahri Canlı Connect, işletmenizin WhatsApp Business hesabını Message Manager
(message-manager.tr) platformu üzerinden yönetmenizi sağlar:

* Ekip gelen kutusu — gelen ve giden mesajlar
* Konuşma bazlı yanıtlama
* 24 saatlik müşteri hizmetleri penceresi kontrolü

Tüm API çağrıları WordPress sunucunuzdan yapılır; tenant API anahtarı tarayıcıya
gönderilmez.

== Installation ==

1. Eklentiyi `/wp-content/plugins/bahricanli-connect` dizinine yükleyin.
2. Eklentiyi etkinleştirin.
3. "Connect → Ayarlar" ekranından Message Manager panelinden aldığınız API
   anahtarını girin ve bağlantıyı test edin.
